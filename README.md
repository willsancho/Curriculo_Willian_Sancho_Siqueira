# Modelo de Currículo Web & PDF

Um modelo moderno de currículo/CV desenvolvido em HTML5 e CSS3 puro, otimizado para visualização web e exportação para PDF impresso em formato A4 sem quebras indesejadas de página.

## Funcionalidades

- **Layout Grid Moderno:** Sidebar ajustada proporcionalmente para destaque do conteúdo principal.
- **Otimizado para Impressão/PDF:** Regras `@media print` configuradas para manter a sidebar de borda a borda e incluir espaçamentos no topo das páginas.
- **Barra de Ações Oculta na Impressão:** Botões de controle no topo da tela para exportação rápida.
- **Modo Econômico (Ink Saver):** Opção de tema claro para economizar tinta ao imprimir.
- **Design Responsivo:** Adaptação fluida para navegação em dispositivos móveis.

## Tecnologias Utilizadas

- **HTML5** (Semântico)
- **CSS3** (Variáveis CSS, Flexbox, Grid e Media Queries)
